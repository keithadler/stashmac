Getting started: three steps

  1. Make a key. Click Make a Key. The app shows your recovery card: 24 words and a QR code. Print it or save the PDF, then put it somewhere safe. This is the only way to read the backup, ever.
  2. Choose folders to protect. Documents and Desktop are the usual first two. Photos libraries, project folders and anything else you'd miss.
  3. Choose where it goes. Any folder that another app already syncs: your iCloud Drive, Google Drive, OneDrive or Dropbox folder, or an external disk or NAS. Then click Back Up Now.
Two destinations are safer than one. Accounts get locked, disks fail. Adding a second one costs nothing.

The recovery card

Stash for Mac makes a random key. There is no password to remember, and the app never keeps a copy of the card. The key lives in this Mac's Keychain for daily use, and on the card for everything else.

  • 24 words in a standard word list, with a checksum: a mistyped word is caught before any restore starts.
  • A QR code of the same key. Scan it with the phone camera, or with Stash for Mac on a new Mac.
  • A fingerprint, eight characters, so two cards can be told apart.
If the card is lost and this Mac is gone, the backup cannot be read by anyone, including you. That is the point of it being secure. Keep the card like a passport.

Where to put it

DestinationHow
iCloud DriveChoose the iCloud Drive folder (or any folder inside it). Files sync on their own.
Google Drive, OneDrive, DropboxInstall the provider's Mac app once, then choose its folder (usually under Library › CloudStorage or your home folder).
External disk or NASChoose any folder on it. When it is unplugged, scheduled backups skip it and catch up later.

Inside the destination, the backup lives in a folder called Stash for Mac, one subfolder per key. Everything in it is encrypted. A README in that folder tells whoever finds it what it is and how to restore it.

Leaving things out

Settings › Skip takes name patterns like *.tmp or Caches and a size cap. By default temp files, cache folders, virtual-machine disks and Photos libraries are skipped: the Photos library is one enormous package that changes every time you open it and has its own backup through iCloud. The backup report says how many files your rules skipped. stashmac exclude add "*.mov" and stashmac exclude --max-mb 2048 do the same from the terminal.

Restoring

On this Mac: pick a snapshot in the window and click Restore…. A tree of everything in that snapshot opens: pick files or folders (⌘-click for several) or leave nothing selected to restore it all, then choose where the files should go. They arrive in a folder named after the original, with their dates. Nothing is written over your current files unless you choose that folder.

On a new Mac: install Stash for Mac, click I Have a Recovery Card…, type the 24 words (or use stashmac key restore --qr card.png with a photo of the card), add the destination folder, and the snapshots appear.

If a piece of the backup is damaged, that one file is reported by name and not written; every other file restores normally.

Space and snapshots

Every backup makes a snapshot, but a snapshot is not a copy. Files are split into pieces and each piece is stored once, so thirty snapshots of an unchanged folder cost about the same as one. What takes space is old versions of files that changed: edit a 200 MB video ten times and ten versions of it are kept until their snapshots go.

Manage Snapshots in the main window lists every snapshot with its size and, in the Frees column, what deleting just that snapshot would give back. Delete any one of them. The window also shows the total the stash is using at the destination.

Two automatic policies, chosen in the same window or in Settings, run after each backup:

  • Keep the newest N (30 by default).
  • Thin out over time: everything from the last week, one a day for a month, one a week for a year, one a month after that. Good for folders that change often.

In the terminal: stashmac snapshots shows the same numbers, stashmac forget <snapshot> deletes one, stashmac prune --thin applies the thinning policy now.

Checking it works

Verify opens every piece of the latest snapshot and restores one random file to a temporary place to prove the whole path. Settings › "Check the backup once a week" does this on its own. A backup that has never been verified is a guess.

Command line

stashmac key new | show | card card.pdf | restore "<24 words>" | restore --qr card.png | forget
stashmac add ~/Documents           stashmac dest "~/Library/CloudStorage/GoogleDrive-you@gmail.com/My Drive"
stashmac backup                    stashmac snapshots
stashmac restore latest ~/Desktop/Restored [--only photos/2024]
stashmac verify                    stashmac status

Every command takes --json. Exit codes: 0 fine, 1 something to look at, 2 problem.

Privacy

The provider receives only encrypted pieces with meaningless names, and an encrypted list of what they belong to. It can see when you back up and roughly how much, nothing more. The app itself has no account, no telemetry, and makes no network connection of its own; the only traffic is the provider's app syncing its folder. The daily update check is one request to GitHub with no identifiers, and nothing installs by itself; it and opening at login are both toggles in Settings.

Not protected: a Mac with malware running while the app is open, a lost card, or someone with your account deleting the encrypted files. The full threat model is in the repository.

Troubleshooting

"No destination is reachable"

The disk is unplugged or the cloud folder has moved. Reconnect it, or add another destination.

Some files were "listed, not downloaded"

They exist only in the cloud (an iCloud placeholder, say). Stash for Mac will not make your provider download them behind your back. Open them once, or turn off "Optimize Mac Storage" for that folder, and the next backup includes them.

Restore says a file failed

A piece was damaged or changed after upload. Try the other destination; the same file there is usually fine.

I lost the card but this Mac still works

Open the window, click the key in the corner, print a new card now.
